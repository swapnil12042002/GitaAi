## About

Gita AI is a full-stack generative AI project that brings the Bhagavad Gita into an AI-powered experience. Its frontend is built with React and TypeScript; its Java/Spring backend integrates Google's GenAI SDK to work with Gemini models. This showcase brings both source repositories and the deployed frontend together in one place.

The backend dependencies confirm Google GenAI SDK integration alongside authentication and persistent-data technologies. **Gemini is a core part of the project's generative AI stack.** See the linked source for exact prompts, model configuration, and current behavior; those details may vary with implementation and deployment settings.

## Repository layout

The project is split across independently maintained repositories:

- [Frontend source](https://github.com/swapnil12042002/gita-ai-frontend)
- [Backend source](https://github.com/swapnil12042002/gita-ai-backend)

Both repositories include their own development and configuration files. Consult each repository for current setup instructions, environment variables, and commands.

## Run locally

Start with the instructions in the source repositories:

1. Review the [frontend repository](https://github.com/swapnil12042002/gita-ai-frontend), including its `.env.example` file.
2. Review the [backend repository](https://github.com/swapnil12042002/gita-ai-backend) for server and database configuration.
3. Configure required credentials and secrets in your local environment. Never commit secret values.

## Deployment

The frontend is deployed at [gita-ai-frontend-drab.vercel.app](https://gita-ai-frontend-drab.vercel.app/auth). Gemini credentials and backend settings should be configured through environment variables; never commit API keys. For backend hosting and current API setup, refer to the [backend repository](https://github.com/swapnil12042002/gita-ai-backend).
